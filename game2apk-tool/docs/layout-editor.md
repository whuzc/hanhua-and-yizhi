# 悬浮按键布局编辑

## 桌面端预览

`game2apk-ui.exe` 的“悬浮按键布局”卡片会在构建前显示一个可拖动预览。选择按键后可以修改显示名称、KeyboardEvent `keyCode`、点按/按住模式和可见性；右侧确认、取消、ESC、立绘键可以隐藏或改绑，也可以添加最多 32 个 `custom_*` 按键。方向键默认固定为左侧四向按键，仍然使用 37/38/39/40 并保持按住时持续输入。

预览会拒绝可见按键重叠，并在提交构建时再次由 Python 和 Android 模板校验。隐藏的按键不会占用碰撞区域；“恢复默认”会清除本次构建的布局改动。

## APK 运行时编辑

启动游戏后，点击右上角“布局”入口，选择“开启拖动与编辑”。此时：

1. 拖动任意可见按键可调整位置；松手后会保存。
2. 点按按键而不是拖动，会打开编辑框。方向键只能改显示位置，右侧和自定义按键可以改名、改键值、切换点按/按住或隐藏。
3. “添加自定义按键”会在右侧寻找不重叠位置，并让用户输入标签和键值。
4. “恢复默认布局”恢复生成 APK 时的布局和绑定；“关闭布局编辑”返回正常游戏输入。

运行时设置写入应用自己的 `SharedPreferences`，不会写入游戏 `www`、外部资源包或存档。使用相同包名和签名覆盖更新时，布局设置会保留；卸载或清除应用数据会清除它们。布局入口和编辑对话框只在悬浮层中运行，不会改变 MV 页面本身的触屏交互。

## 超大项目与音频修复

当 `www` 预计接近 APK ZIP32 限制时，工具会输出“APK 主程序 + `*-resources.g2ares` 外部资源包”。APK 的静态验收会读取资源包清单，不再把“桥接脚本只在资源包中”误报为缺失。手机运行时仍需把资源包放到应用专属目录：

```text
/Android/data/<applicationId>/files/game2apk/<fileName>.g2ares
```

资源包路径由 APK 的 `resource-pack.json` 决定，不能改名或解压。WebView 资源处理器会对 URL 做一次 URI 解码，因此中文、空格和非 ASCII 音频名可以正常读取。

RPG Maker MV 的移动端 UA 常导致默认请求 `.m4a`。构建阶段现在扫描实际暂存的 `www/audio`，为每个音频名写入扩展名映射：OGG/加密 OGG 优先使用 `.ogg`/`.rpgmvo`，只有存在 M4A 时才请求 `.m4a`/`.rpgmvm`。这同时覆盖单 APK 和外部资源包模式。

## 验证边界

桌面工具会执行 Gradle、签名、zipalign、aapt/apksigner 和资源清单静态验收。没有连接 Android 设备时，报告不会宣称已经完成实机启动、音频路由或触屏验证；新 APK 必须用新版工具重新构建，旧 APK 中的桥接脚本不会自动更新。
